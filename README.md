# Maschine MK2 Works in Maschine 3

<img width="1243" height="634" alt="Maschine MK2 Works in Maschine 3" src="https://github.com/user-attachments/assets/07cacfa8-aee2-42aa-b85f-bce3ba61ccf8" />

Use your **Maschine MK2** with Maschine 3 on Windows or macOS.

> [!CAUTION]
> **Maschine Jam will not work while the MK2 is enabled.** Select **Restore original** to use Jam again.

This is an unofficial project. You need your own installed and activated copy of Maschine 3 and the **Maschine Controller MK2 Driver**.

## macOS

1. Download the macOS ZIP from [Releases](../../releases) and extract it.
2. Close Maschine 3 and open **MK2 Activator**.
3. Click **Enable MK2** and enter your Mac administrator password.
4. Connect your MK2 and open Maschine 3.

To undo the change, close Maschine and select **Restore original**. If the activator cannot find a matching backup, repair Maschine 3 using Native Access.

Requires macOS 11 or later and Python 3 (available with the Xcode Command Line Tools). Tested with an MK2 on an Intel Mac running Maschine 3.3.0. Apple Silicon hardware and other versions have not yet been tested with a controller; unsupported builds are refused.

## Windows

1. Download **MK2 Activator.exe** from [Releases](../../releases).
2. Close Maschine 3 and open the activator.
3. Click **Enable MK2**, then connect your MK2 and open Maschine 3.

To undo the change, select **Restore original** or repair Maschine 3 using Native Access. Windows 10 or 11 is required. Versions 3.6.0 and 3.7.1 have been analyzed and tested; other versions are only patched when the expected code is found.

**After updating Maschine 3**, run the activator again.
