OBSIDIAN MK2 CONNECT
====================

Connect your MK2 controller on Windows.

WARNING: The Jam controller will not work while the MK2 is enabled.
Use "Restore original" to use Jam again.

BEFORE YOU START
- Install and activate the compatible version 3 software using your software provider’s installer.
- Install the MK2 controller driver.
- This is unofficial software. Use it at your own risk.

HOW TO ENABLE THE MK2
1. Close the music software.
2. Open "MK2 Activator.exe" and allow it to make changes.
3. Click "Enable MK2".
4. Connect the MK2 and open the music software.

HOW TO RESTORE THE ORIGINAL
Open the activator and click "Restore original". You can also repair the music software using your software provider’s installer.

After a software update, run the activator again.
